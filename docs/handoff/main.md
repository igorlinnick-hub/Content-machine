## Состояние
**Рабочая копия — `~/Code/Content-machine`** (старый путь в `~/Documents` — симлинк). **Деплой по `git push`**;
`vercel --prod` руками не гонять — CLI грузит незакоммиченное. Прод — `content-machine-gules.vercel.app`,
`/api/version` отдаёт sha; админ-запрос = `Cookie: cm_admin=$ADMIN_KEY`, а `+ cm_view_as=<clinicId>` рендерит
экран глазами врача. Локально приложение **не поднять**: в `.env.local` нет ни `ADMIN_KEY`, ни ключей
Supabase — UI-правки проверяются на проде.

**В репозитории работают две сессии одновременно** (эта и Yedino). `tsc` локально видит рабочую копию
целиком, а Vercel — только коммит, поэтому **обе половины правки должны ехать одним коммитом**. Дважды
уронили сборку именно этим (16.09 `planner.ts` без `formats.ts`, 17.09 `writer.ts` без `profiles.ts`).
Проверка перед пушем дешёвая: `git worktree add --detach <tmp> HEAD`, симлинк `node_modules`, `npx next build`.

**Роли (16.09).** Скрипты генерит только админ (403 клиничному токену, вкладка Generate скрыта). Видео врач
**смотрит, но не скачивает**: ни чипов папок Drive, ни «Open in Drive», плюс `copyRequiresWriterPermission`.

**Плеер `/videos` больше не iframe Drive.** Drive не отдаёт файл в свой `/preview`, пока не сделает
собственную перекодировку, — свежий дубль встречал врача надписью «still being processed for playback».
Телесуфлёр пишет H.264/mp4, телефон декодирует его сам, поэтому байты идут через свой роут
`/api/recordings/[fileId]/stream` (кука + проверка, что fileId принадлежит своей клинике; `Range`
пробрасывается, иначе Safari ломает перемотку). Iframe остался фолбэком по `onError` — старые WebM-дубли
с десктопного Chrome Safari не декодирует. Цена решения: залогиненный врач технически может вытащить
байты по этому URL — маленькая трещина в watch-only от 10.09.

**Удаление подтверждается внутри страницы, не `window.confirm`.** iOS Safari разрешает заглушить диалоги
страницы, после чего `confirm()` молча возвращает `false` — все кнопки Delete выглядели мёртвыми. Теперь
корзина открывает оверлей на карточке, а ошибка запроса привязана к дублю и видна и под плеером, и под
карточкой (раньше молчали оба).

**Телесуфлёр знает 16:9** (`e6d38c8`): поворот телефона сам переключает раскладку, кнопка `16:9`/`9:16` —
запасной путь при блокировке поворота. У ландшафта свой кегль (56 px против 30, регулятор `A−/A+` 28–120),
обе панели уходят в overlay. Позиция чтения хранится долей, не пикселями.
