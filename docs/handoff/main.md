# Main — доступы (install-ссылки и коды входа)

Обновлено: 2026-08-13 · ветка: main

## Состояние
Вход в прод (`content-machine-gules.vercel.app`) — два эквивалентных способа
на одну и ту же сессию (cookie на год): ссылка `/c/<token>` и memorable-код,
который вводится на экране входа на главной. Выпуск и отзыв — только в UI:
`/clinics` → клиника → блок install-ссылок (`InstallLinkCard`). Роли: `doctor`
(тонкая поверхность) и `editor` (полный back-office).

Клиник в проде две, обе называются «Hawaii Wellness Clinic», различаются
доктором:
- Dr. Shawn (TMS / Ketamine) — `5065c6ee-7c4b-451b-8dee-3498eb3af674`, дефолтная
- Dr. Made (Botox / Fillers) — `cdb530e5-3ce9-4088-abee-117bc872e39a`

У обеих есть активные doctor- и editor-ссылки с кодами. Сами коды и токены
намеренно НЕ записаны здесь — это боевые учётки, смотреть в `/clinics`.

## Последний заход
- Выпущена общая editor-ссылка на дефолтную клинику (label «Everyone») —
  доступ ко всему back-office, кому дашь код.
- Проверено, что у клиники Dr. Made обе ссылки уже существовали и ни разу
  не использованы — дубликаты не плодил.
- Выпуск делался через залогиненный Safari (своё окно по id, `fetch` на
  `/api/admin/install-link`), окно закрыто. Прямой путь через Supabase REST
  не сработал: Bash-песочница подменяет значения секретов из `.env*` на
  `[SENSITIVE]`, ключ до curl не доезжает.
- Грабли Safari-автоматики: `do JavaScript` не возвращает результат промиса —
  писать в `window.__x` и читать вторым вызовом после `delay`.
- Код репозитория не менялся.
