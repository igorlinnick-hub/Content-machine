# scripts

Обновлено: 2026-10-14 · ветка: main

## Состояние
/scripts: вкладки Scripts / Generate / Notes. Админ генерирует, ставит звезду, и скрипт
попадает врачу (у врача список = только starred). Есть **«+ Add your own script»** (только
админ): свой текст сохраняется строкой в `scripts` с `source='manual'` (миграция 065, применена
к проду), хук = первая произносимая строка. Перед сохранением прогоняется тот же compliance-гейт,
что у генерации, вердикт лежит в `scripts.compliance` (050). Если проверка не прошла, ничего не
сохраняется. В карточке есть панель вердикта: находки, «Fix wording for me» (тот же цикл
`convergeCompliance`, текст сохраняется сразу) и «Check again». Звезда заблокирована (UI + 409 на
сервере) при REMOVE/REWORD или если свой скрипт не проверен. Правило в `lib/scripts/manual.ts`.
**HireDrop гейт не проходит** (`nicheIsScreened` в `lib/niche/profiles.ts`). Это аккаунт Игоря под его
собственные скрипты: вставил, прочитал в телесуфлёре, запись ушла в Drive
`Content Machine/Recordings/HireDrop`. Сохранение мгновенное, без вердикта, звезда не блокируется.

## Последний заход (2026-10-14)
- Своё не удаляется автоочисткой: `pruneOldScripts` считает окно 30 только по машинным строкам.
- Любая правка текста строки с вердиктом (своя, Studio) перепроверяет его в PATCH, в том числе
  правка из телесуфлёра. Если гейт упал, правка сохраняется, а вердикт = null («не проверен»).
- Грабли: `runCompliance` при падении LLM НЕ бросает ошибку, а возвращает REVIEW с
  `model:'gate-error'`. Для своих скриптов это «не проверен» (`gateRan()`), иначе звезда открылась
  бы без проверки.
- Грабли: отдельно введённый хук устаревал после правки тела и снова получал флаг. Для manual
  хук теперь всегда берётся из первой строки, поле Hook в форме для них скрыто.
- Проверено на проде с живым гейтом (`92aab78`): создание ~8 с, REMOVE → «Fix» отказан,
  REWORD → «Fix wording» → PASS за ~6 с → звезда ставится. Вердикты LLM нестабильны: одна и та же
  фраза бывает то REWORD, то REMOVE. UI проверен в Chrome (десктоп и телефон), тестовые строки удалены.

## Сломано / не доделано
- У HireDrop по-прежнему нет NicheProfile: генерация для него (Generate) писала бы голосом regen-med.
  Сейчас не нужно, Игорь только вставляет свои скрипты.
- Studio-строки с REWORD теперь тоже нельзя отметить звездой. Это новое поведение, сознательно.
- `pruneOldScripts` по-прежнему может удалить starred машинный скрипт (старая дыра, не трогал).
