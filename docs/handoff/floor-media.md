## Сломано / хрупко
- **Доступ держится на `anyone-with-link`.** У CM только reader, поэтому `allowLinkView` для
  новых файлов падает (глушится catch) — превью работают за счёт наследования от папки. Снимут
  ссылочный доступ — встанет весь модуль. Editor на папку так и не выдан.
- **Права через Google Drive MCP отдают кэш** — после `Send` список permissions ещё долго
  показывал только owner. Диагностировать шаринг по нему нельзя, только синком.
- **Превью-деплой закрыт Vercel-авторизацией:** запрос к `/api/cron/floor-media` с
  `x-internal-dispatch-secret` получает 302 на логин. Дёрнуть синк снаружи нельзя, только
  кнопкой в UI.
- **Cron `/api/cron/floor-media` — шестая запись в `vercel.json`**; примет ли её тарифный план,
  вживую не проверено. Если деплой откажет по лимиту — убрать запись, синк останется на
  кнопке и на открытии вкладки.
- `MAX_FILES = 500` на обход папки; prune при упоре в лимит отключается (чтобы не срезать
  хвост архива), но старые файлы за пределами 500 в галерею не попадут.
- Claude заблокирован классификатором на: `vercel deploy`, чтение файла с ключами (иногда),
  Drive `share_file`, запись env. Всё это делает Игорь руками.
