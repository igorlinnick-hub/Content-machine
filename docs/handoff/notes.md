# Notes — блокнот идей рядом с Generate

Обновлено: 2026-09-23 · ветка: main

## Состояние
Вкладка **Notes на `/scripts`** (рядом с Generate), видна админу и врачу. Идея Игоря: свалка мыслей
как попало (RU/EN вперемешку, с бумаги или с клавиатуры), ИИ чинит ТОЛЬКО механику — орфографию,
грамматику, лёгкую группировку по буллету на идею. **Запрещено вшито в промпт** (`lib/agents/note-tidy.ts`):
не сливать, не выкидывать, не переписывать «красивее», не ранжировать, не добавлять своё; сомнение
«одна идея или две» = две.

Хранение: таблица `idea_notes` + публичный бакет `note-photos` — **миграция 057 прогнана в проде**
(`pscqjvkuqqmvmcbxdwtu`, через `supabase link` + `db query --linked`, PostgREST перезагружен).
Два текста на заметку: `raw_body` (дословный оригинал, никогда не переписывается) и `body`
(прибранный); на карточке «View original» и ревёрт. Tidy — best-effort: упал или агенты выключены —
заметка сохраняется сырой (`tidy_status = raw|tidied|failed`).

Фото с бумаги: кнопка «Snap a paper note» (`capture="environment"`, до 4 страниц ≤8 МБ JPEG/PNG/WebP)
→ страницы сначала в бакет (бумага = первоисточник) → **Sonnet** транскрибирует дословно
(`[unreadable]` + флаг на нечитаемое, зачёркнутое пропускает с флагом) → tidy (Haiku) поверх.
Флаги обеих стадий — сноской под заметкой. API: `app/api/notes/ideas/route.ts` (GET/POST/PATCH
с action `revert|retidy`/DELETE, доступ по клинике) и `.../photo/route.ts`; стор — `lib/notes/ideas.ts`;
UI — `app/scripts/components/NotesWorkspace.tsx` (пин, правка, удаление чистит бакет).

`idea_notes` дописана в `types/supabase.ts` руками — следующий `npm run typegen` перегенерит её сам.
Старый `/api/notes` (doctor_notes → Analyst) не тронут: другой жизненный цикл, таблицы не связаны.
