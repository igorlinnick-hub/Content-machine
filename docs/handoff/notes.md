# Notes — блокнот идей рядом с Generate

Обновлено: 2026-10-03 · ветка: main

## Состояние
Вкладка **Notes на `/scripts`** (рядом с Generate), видна админу и врачу. Три входа:
печатный текст, фото с бумаги, голос. Контракт вшит в промпт (`lib/agents/note-tidy.ts`):
ИИ чинит ТОЛЬКО механику — орфографию, грамматику, лёгкую группировку; не сливать, не выкидывать,
не переписывать «красивее», не ранжировать. Два текста на заметку: `raw_body` (дословный оригинал)
и `body` (прибранный), «View original» и ревёрт на карточке. Tidy best-effort: упал/выключен —
заметка сырая.

Сомнительные слова — не проза, а структура (`tidy_issues`, миграция 058): на карточке слово +
1-3 варианта кнопками + ✏️ свой + «keep»; тап правит body и гасит issue. Заметки лежат
горизонтальной свайп-лентой (новые слева, счётчик с датой); пока фото/голос обрабатывается —
живая карточка со стадиями вверху ленты.

Фото: «Snap a paper note» (до 4 страниц ≤8 МБ) → бакет `note-photos` (бумага = первоисточник) →
Sonnet-вижн дословно → tidy (Haiku), сомнения транскрайбера становятся кнопками. Требует
`ENABLE_LLM_AGENTS=true` (подтверждён живьём 23.09). Голос (03.10): «🎤 Say it» → MediaRecorder
(mp4/AAC на iPhone, webm/opus в Chrome, автостоп 10 мин) → запись в тот же бакет (`audio_url`,
плеер на карточке) → WhisperX на Replicate (`lib/clips/whisper.ts`, общий с клипами; работает и
без LLM-агентов — заметка тогда сырая) → tidy. Роуты: `app/api/notes/ideas/route.ts` (+`photo`,
`audio`), стор `lib/notes/ideas.ts`, UI `app/scripts/components/NotesWorkspace.tsx`.
Миграции 057-059 прогнаны в проде. В `/visual` NotesPopover: идея из Notes → тема поста.
