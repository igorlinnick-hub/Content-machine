# Мастер-шаблон отстаёт молча: Aesthetic жил на старом текстовом стандарте

**Дата:** 2026-08-27 · **Модуль:** Canva / posts · **Мастер:** `DAHMHS1wLls` (canva_style 5, Made)

## Симптом

Игорь: «шаблон для Aesthetic имеет старый текст, подогнать к стандарту как у остальных».
Обложка выглядела нормально — дефект жил на страницах 2–7, куда никто не смотрел.

## Что оказалось

Мастера 1–4 пересобрали 2026-08-10 в editorial-стандарт; пятый — нет. Он остался копией
старого ED-поста:

| | Style 1 (стандарт) | Aesthetic (было) |
|---|---|---|
| строка заголовка | 80 units | 52 units (~2/3) |
| строка body | 67 units | ~41 units |
| текст слайда | ≤ 20 слов, пустая строка между пунктами | 60–100 слов сплошняком |
| списки | литеральные `✓` / `①` | нативные були Canva |
| низ страницы | текст кончается ≈1240 | текст уходил ЗА 1350 (обрезался) |

Раннер копирует мастер и **наследует его размеры шрифта** (правило «шрифт не менять
послайдово»), поэтому каждый пост Made выходил в старой типографике.

## Как чинили (без Enterprise-фич, только Canva MCP)

- Размеры шрифта из API не читаются — их считают из высоты бокса: `height = lines × font × line_height`.
  Style 1: заголовок 80/строка, body 67/строка → `font_size` 67 / 56 при `line_height` 1.2.
  Проверка после операций: боксы вернулись 80 / 268 (4 строки) / 335 (5 строк) — совпало со Style 1.
- Диагональные/волновые панели через MCP **не адресуются** (в `richtexts`/`fills` их нет) —
  panel-fit на этих мастерах невозможен; текст подгоняют под панель, не наоборот.
- 54 операции ушли **одним** `perform-editing-operations` — каждый вызов возвращает картинку страницы,
  которая потом висит в контексте до конца сессии.
- `find_and_replace_text` вместо `replace_text` там, где в элементе живёт вёрстка (в пилюле обложки
  строка 1 — это `"Peptides\n<пробелы>"`; замена целиком схлопнула бы бокс и увела бы слово с центра).
- Бэкап до правки: `copy-design` → `DAHTh7vDmxM` («BACKUP 2026-08-27 …»).

## Правило на будущее

Мастер — это код. Когда стандарт меняют, **проверять все мастера пофайлово (страницы 2+, а не обложку)**
и держать в `style-templates.ts` дату последней сверки. Дрейф мастера не падает с ошибкой — он тихо
выходит в готовых постах клиента.
